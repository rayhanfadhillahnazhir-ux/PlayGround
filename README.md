## Play locally

This is a browser-playable vertical slice. From the project directory, start a local web server:

```sh
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). The game loads Three.js from jsDelivr, so an internet connection is needed.

### Controls

- **Desktop:** WASD / arrow keys to move, mouse to look (click the game first), **E** to interact, **1 / 2 / 3** to switch between Past / Now / Future, **Shift** to run, **J** for the journal.
- **Touch:** use the left virtual stick to move, drag the scene to look, and use the on-screen action buttons.

Progress is stored in this browser with `localStorage`; **New Game** clears the current run. The playable build includes the Entrance gallery and three temporal puzzles. The other museum pavilions are story/map teasers only; native Android/iOS packaging and the full campaign are not included.
